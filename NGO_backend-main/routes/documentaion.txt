1. Auth Routes
POST /api/auth/register
Purpose: Register a new user (donor or NGO admin).

Request Body:

json

{
  "email": "user@example.com",
  "password": "securePassword123",
  "role": "USER" // or "NGO_ADMIN"
}
Response:

json

{
  "id": "user_id",
  "email": "user@example.com",
  "role": "USER",
  "createdAt": "2023-10-01T12:00:00Z"
}
Example:

curl -X POST http://localhost:3000/api/auth/register \
-H "Content-Type: application/json" \
-d '{"email": "user@example.com", "password": "password123", "role": "USER"}'
POST /api/auth/login
Purpose: Authenticate a user and return access/refresh tokens.

Request Body:

json

{
  "email": "user@example.com",
  "password": "securePassword123"
}
Response:

json

{
  "accessToken": "jwt_access_token",
  "refreshToken": "jwt_refresh_token"
}
Example:

curl -X POST http://localhost:3000/api/auth/login \
-H "Content-Type: application/json" \
-d '{"email": "user@example.com", "password": "password123"}'
POST /api/auth/logout
Purpose: Log out a user by clearing cookies/tokens.

Headers:

Authorization: Bearer <accessToken>

Response:

json

{
  "message": "Logged out successfully"
}
Example:

curl -X POST http://localhost:3000/api/auth/logout \
-H "Authorization: Bearer <accessToken>"
POST /api/auth/refresh
Purpose: Refresh an expired access token using a refresh token.

Request Body:

json

{
  "refreshToken": "jwt_refresh_token"
}
Response:

json

{
  "accessToken": "new_jwt_access_token"
}
Example:

curl -X POST http://localhost:3000/api/auth/refresh \
-H "Content-Type: application/json" \
-d '{"refreshToken": "<refreshToken>"}'

2. NGO Routes
POST /api/ngos
Purpose: Create a new NGO (only for NGO_ADMIN role).

Headers:

Authorization: Bearer <accessToken>

Request Body:

json

{
  "name": "Example NGO",
  "description": "Helping the community",
  "website": "https://example.org"
}
Response:

json

{
  "id": "ngo_id",
  "name": "Example NGO",
  "description": "Helping the community",
  "website": "https://example.org",
  "createdAt": "2023-10-01T12:00:00Z"
}
Example:

curl -X POST http://localhost:3000/api/ngos \
-H "Authorization: Bearer <accessToken>" \
-H "Content-Type: application/json" \
-d '{"name": "Example NGO", "description": "Helping the community", "website": "https://example.org"}'

json

3. Donation Routes
POST /api/donations
Purpose: Create a donation.

Headers:

Authorization: Bearer <accessToken>

Request Body:

json

{
  "amount": 1000,
  "ngoId": "ngo_id",
  "paymentMethod": "UPI" // or "CARD"
}
Response:

json

{
  "id": "donation_id",
  "amount": 1000,
  "status": "PENDING",
  "paymentLink": "https://rzp.io/l/example"
}
Example:

curl -X POST http://localhost:3000/api/donations \
-H "Authorization: Bearer <accessToken>" \
-H "Content-Type: application/json" \
-d '{"amount": 1000, "ngoId": "ngo_id", "paymentMethod": "UPI"}'
POST /api/donations/webhook
Purpose: Handle payment webhook notifications from Razorpay.

Request Body (Razorpay format):

json

{
  "event": "payment.captured",
  "payload": {
    "payment": {
      "entity": {
        "id": "payment_id",
        "amount": 1000,
        "status": "captured"
      }
    }
  }
}
Response:

json

{
  "message": "Webhook processed"
}
